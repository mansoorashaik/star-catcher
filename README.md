# ⭐ Star Catcher

A small arcade game that runs in the browser. Move the paddle to catch falling stars and avoid the bombs. The game gets faster as you score.

## How to play
- **Mobile:** drag your finger across the game area
- **Desktop:** use the ← and → arrow keys, or move the mouse
- Catch ⭐ to score a point
- Hitting a 💣 or missing a ⭐ costs one life
- You have 3 lives. Your best score is saved in your browser.

## Run it locally
Download `index.html` and open it in any browser. No installation needed.

## Built with
- HTML5 Canvas
- Vanilla JavaScript
- CSS (light and dark mode supported)
